# QuantLab · 金融研究工作台

面向金融机器学习学习者的作品集原型。无需注册、API密钥或依赖安装，打开index.html即可体验。

## 演示内容

1. 数据检查：180条确定性模拟行情、CSV导入、重复日期和OHLC检查、图表及记录预览。
2. 模拟买入持有：初始100,000元，首日开盘买入100份整数倍，买入成本0.10%，现金不计息、无分红、期末不卖出。
3. 基本面指标：完全虚构公司的年度指标、图表和CSV导出；不对应真实公司。

累计收益相对初始资金计算。最大回撤按首日起日终净值峰值计算，不包含日内回撤；图表分别以各曲线首日值归一为100。

所有用户导入的行情均标记为待核验，暂停回测；可点击恢复模拟行情返回演示。文件仅在浏览器本地处理，不上传，刷新后清除。

## 项目边界

研究演示，非投资建议。模拟收益不是实际ETF业绩。尚未完成真实数据准入、机器学习、样本外评估和用户访谈验证。

本目录是独立公开演示包；不包含原项目的真实行情、原始材料或本地路径。财务案例已替换为完全虚构数值。
